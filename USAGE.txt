================================================================================
  [서울교육대학교] AI 지능형 시험 자동 채점 & 통계 리포트 시스템 사용 설명서
================================================================================

본 시스템은 교사용 시험 3대 문서(문제지, 답안지 양식, 정답 및 배점기준표)와
학생들이 손글씨로 작성한 답안지를 인공지능(Upstage Document AI & Solar LLM)으로
정밀 분석하여 자동 채점하고, 학과별 맞춤 엑셀 성적표와 상세 피드백을 제공합니다.


--------------------------------------------------------------------------------
1. 최초 1회 실행 전 준비사항
--------------------------------------------------------------------------------
1) 파이썬(Python) 설치:
   - 컴퓨터에 파이썬 3.10 이상이 설치되어 있어야 합니다.
   - 미설치 시 공식 사이트(https://www.python.org/downloads/)에서 설치해 주세요.
   - ※ Windows 설치 시 맨 아래 "Add Python to PATH"에 반드시 체크해 주세요!

2) Upstage API 키 발급 및 등록:
   - Upstage 콘솔(https://console.upstage.ai)에서 회원가입 후 API Key를 발급받습니다.
   - 본 폴더 안의 [.env] 파일(또는 실행 시 자동 생성되는 .env 파일)을 메모장으로 엽니다.
   - 아래와 같이 발급받은 키를 따옴표 없이 입력하고 저장합니다:
     
     UPSTAGE_API_KEY=up_xxxxxxxxxxxxxxxxxxxxxxxxxxxx

   ※ 보안 주의: API 키는 화면에 노출되지 않으며 오직 .env 파일에서만 안전하게 읽힙니다.


--------------------------------------------------------------------------------
2. 프로그램 실행 방법 (원클릭 실행)
--------------------------------------------------------------------------------
- Windows (윈도우) 사용자:
  폴더 내의 [ run.bat ] 파일을 마우스로 더블 클릭합니다.
  (필수 라이브러리가 자동 설치되고 웹 브라우저가 자동으로 열립니다.)

- Mac / Linux (맥) 사용자:
  터미널을 열고 본 폴더로 이동한 뒤 아래 명령을 실행합니다:
  ./run.sh

- 수동 실행 방법 (공통):
  터미널 또는 명령 프롬프트(CMD)에서 아래 명령어를 차례로 입력합니다:
  pip install -r requirements.txt
  streamlit run app.py


--------------------------------------------------------------------------------
3. 단계별 시험 채점 사용 가이드
--------------------------------------------------------------------------------

[Step 1] 교사 시험 자료 3대 파일 업로드
  1. [1. 문제지 파일] (PDF 또는 이미지)을 업로드합니다.
  2. [2. 답안지 파일 (양식)] (학생들이 작성하는 빈 답안지 서식)을 업로드합니다.
  3. [3. 정답 및 배점기준표] (PDF, 이미지, 엑셀, 텍스트)를 업로드합니다.
  4. '🔍 3대 문서 융합 AI 기준표 생성' 버튼을 클릭합니다.
  5. AI가 세 문서를 대조하여 생성한 [문항 번호, 유형, 배점, 기준 정답] 표를 확인하고,
     필요한 경우 화면에서 직접 내용을 수정한 뒤 '💾 기준표 최종 확정'을 누릅니다.

[Step 2] 학생 손글씨 답안지 일괄 업로드 및 채점
  1. 스캔된 학생 답안지 파일들(PDF, PNG, JPG)을 드래그 앤 드롭으로 한 번에 올립니다.
  2. '🚀 업로드된 학생 답안 전체 일괄 채점 시작' 버튼을 누릅니다.
  3. AI가 학생 손글씨의 학과, 학번, 성명과 문항별 답안을 왜곡 없이 판독하여 자동 채점합니다.

[Step 3 & 4] 결과 확인 및 엑셀 다운로드
  1. 상단의 학과별 탭을 선택하여 학생들의 채점 결과표를 미리 확인합니다.
  2. '📥 구글 스프레드시트 맞춤형 엑셀 다운로드 (.xlsx)'를 클릭하면
     학과별 시트 자동 분할 및 3행 헤더(=SUM, =RANK 수식 포함) 성적표가 저장됩니다.
  3. '📊 전체 학생 상세 피드백 & 정오표 종합 (.xlsx)'를 클릭하면
     모든 학생의 상세 문항별 피드백이 담긴 종합 리포트를 다운로드할 수 있습니다.

[수기 검토 및 채점자 최종 정오/득점 확정]
  1. 서술형이나 단답형 문항 중 채점자가 직접 점수를 재조정하고 싶은 경우,
     하단의 [수기 검토 및 채점자 최종 정오/득점 확정] 영역에서 학생을 선택합니다.
  2. 표에서 [정오(O/△/X)] 또는 [득점], [채점 피드백]을 채점자 기준대로 직접 수정합니다.
  3. '💾 채점자 수정한 정오/득점으로 최종 확정 및 엑셀 재계산' 버튼을 누르면,
     채점자의 수정 사항이 즉시 최종 점수로 확정되고 총점과 엑셀 파일이 자동 재계산됩니다.
  4. 수정된 내역은 '📥 [{학생이름}] 피드백 (.xlsx)' 또는 '📄 CSV'로 바로 다운로드 가능합니다.


--------------------------------------------------------------------------------
4. 지능형 채점 특수 규칙 안내
--------------------------------------------------------------------------------
- "A 또는 B" 복수 선택형 정답:
  기준 정답에 "A 또는 B"가 명시된 경우, 'A'만 단독 작성하거나 'B'만 단독 작성한 경우만
  정답(O)으로 인정되며, 'A 또는 B'나 둘 다 적은 경우는 규칙에 따라 오답(X) 처리됩니다.

- 한/영 표기 및 통용 약어 자동 인정:
  '컴퓨터' ↔ 'Computer', '인공지능' ↔ 'AI', '운영체제' ↔ 'OS' 등
  표준 한/영 및 약어 표기는 동일 정답으로 자동 인정됩니다.
  (단, 컴퓨터와 인공지능처럼 서로 다른 개념은 엄격하게 구분됩니다.)


--------------------------------------------------------------------------------
5. 문제 해결 (FAQ)
--------------------------------------------------------------------------------
Q. 웹 브라우저가 자동으로 안 열려요.
A. 웹 브라우저(크롬, 엣지 등) 주소창에 http://localhost:8501 을 직접 입력해 접속하세요.

Q. "API 키가 설정되지 않았습니다"라고 나옵니다.
A. 폴더 내 [.env] 파일을 메모장으로 열고 UPSTAGE_API_KEY= 뒤에 발급받은 실제 키가
   정확히 들어있는지 확인하고 저장한 후 앱을 새로고침하세요.

Q. 채점을 처음부터 다시 하고 싶습니다.
A. 좌측 사이드바의 '🗑️ 새 시험 시작 (데이터 초기화)' 버튼을 클릭하시면 됩니다.
